# Options

Every CLI flag, with real before/after output. Examples are generated by running the tool, so what
you see here is what you get.

Cleaning examples below use `--no-format`-equivalent settings so the output stays on one line and the
change is easy to see. The CLI does not have a `--no-format` flag; add `"format": false` to your
config, or read [configuration.md](./configuration.md). With formatting on (the default), the same
transformations apply and the result is additionally indented.

## Input and output

| Flag                  | Description                                   |
| --------------------- | --------------------------------------------- |
| `-o, --output <file>` | Write the cleaned HTML to a file              |
| `-w, --write`         | Modify the input file in place                |
| `--stdin`             | Read HTML from stdin explicitly               |
| `--stdout`            | Write cleaned HTML to stdout explicitly       |
| `--check`             | Exit `4` when cleaning would change the input |
| `--report`            | Print cleanup statistics to stderr            |

`--write` cannot be combined with `--output`, `--stdin`, or `--stdout`, and requires an input file.
`--output` refuses to overwrite the input file; use `--write` when you mean it.

## Preset and config

| Flag              | Description                                 |
| ----------------- | ------------------------------------------- |
| `--preset <name>` | Apply a named option preset                 |
| `--config <file>` | Read options from a JSON configuration file |

## Cleaning

| Flag                                       | Input                                                  | Output                                          |
| ------------------------------------------ | ------------------------------------------------------ | ----------------------------------------------- |
| `--remove-comments`                        | `<!--keep me out--><p>a</p>`                           | `<p>a</p>`                                      |
| `--remove-styles`                          | `<p style="color:red">a</p>`                           | `<p>a</p>`                                      |
| `--remove-classes`                         | `<p class="x y">a</p>`                                 | `<p>a</p>`                                      |
| `--remove-ids`                             | `<p id="intro">a</p>`                                  | `<p>a</p>`                                      |
| `--remove-attributes`                      | `<a href="/x" title="t" data-v="1">a</a>`              | `<a>a</a>`                                      |
| `--remove-attributes` + `--keep-attr href` | `<a href="/x" title="t">a</a>`                         | `<a href="/x">a</a>`                            |
| `--remove-attr data-a`                     | `<p data-a="1" data-b="2">a</p>`                       | `<p data-b="2">a</p>`                           |
| `--collapse-nbsp`                          | `<p>a&nbsp;&nbsp;&nbsp;b</p>`                          | `<p>a b</p>`                                    |
| `--convert-bold`                           | `<p><b>bold</b></p>`                                   | `<p><strong>bold</strong></p>`                  |
| `--convert-italic`                         | `<p><i>em</i></p>`                                     | `<p><em>em</em></p>`                            |
| `--remove-empty`                           | `<div><p></p><p>keep</p></div>`                        | `<div><p>keep</p></div>`                        |
| `--remove-empty-nbsp`                      | `<div><p>&nbsp;</p><p>x</p></div>`                     | `<div><p>x</p></div>`                           |
| `--remove-spans`                           | `<p><span>text</span></p>`                             | `<p>text</p>`                                   |
| `--remove-links`                           | `<p><a href="#">text</a></p>`                          | `<p>text</p>`                                   |
| `--remove-images`                          | `<p>a<img src="x.png">b</p>`                           | `<p>ab</p>`                                     |
| `--remove-tables`                          | `<table><tbody><tr><td>cell</td></tr></tbody></table>` | `cell`                                          |
| `--tables-to-div`                          | `<table><tbody><tr><td>c</td></tr></tbody></table>`    | `<div><div><div><div>c</div></div></div></div>` |
| `--strip-tags`                             | `<p>a<span>b</span></p>`                               | `ab`                                            |
| `--strip-tags --preserve-breaks`           | `<h1>T</h1><p>a<br>b</p>`                              | `T\na\nb`                                       |

`--keep-attr` and `--remove-attr` are repeatable: pass each name separately.

### Semantics worth knowing

**Unwrapping vs removing.** `--remove-spans` and `--remove-links` _unwrap_: the element goes away
and its content stays. `--remove-images` _removes_: the element and its content both disappear.

**Empty means empty.** `--remove-empty` only removes non-void elements. `br`, `hr`, `img`, `input`,
`meta`, `link`, and other void elements are never removed, because they carry meaning without
content.

**NBSP interacts with two flags.** `--collapse-nbsp` (on by default) turns `&nbsp;` into plain
spaces — which means NBSP-only elements then look empty. `--remove-empty-nbsp` is what allows
whitespace/NBSP-only content to count as empty. To keep an NBSP-only element, turn **both** off.

**Table semantics.** `--remove-tables` _unwraps_ structural elements — `table`, `caption`,
`colgroup`, `thead`, `tbody`, `tfoot`, `tr`, `td`, `th` — replacing each with its children so cell
content and ordering survive. `col`, being void, is deleted outright since it has nothing to keep.
`--tables-to-div` renames those same elements to `div`, preserving hierarchy and child order.
The two are mutually exclusive; if both are given, `--remove-tables` wins.

Note that an HTML parser inserts `<tbody>` even when the source omits it, so `<table><tr><td>c</td></tr></table>`
converts to four nested `div`s, not three.

## Formatting

Formatting is on by default. It operates on the AST, never on HTML text.

| Flag                       | Output for `<div><p>a</p></div>`    |
| -------------------------- | ----------------------------------- |
| default (`indent 2`, `lf`) | `<div>\n  <p>a</p>\n</div>\n`       |
| `--indent 4`               | `<div>\n    <p>a</p>\n</div>\n`     |
| `--indent tab`             | `<div>\n\t<p>a</p>\n</div>\n`       |
| `--newline crlf`           | `<div>\r\n  <p>a</p>\r\n</div>\r\n` |
| `--no-final-newline`       | `<div>\n  <p>a</p>\n</div>`         |

`--indent` accepts a non-negative integer or the literal `tab`. `--newline` accepts `lf` or `crlf`.
An empty result stays empty — cleaning a document down to nothing never leaves a lone newline.
